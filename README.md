# WiFurLab CREA · 自由名片编辑器

本目录是一个独立站点。上传到 GitHub 时，请把目录内的文件放到仓库根目录，确保根目录直接有 index.html。

## EdgeOne Pages

在 EdgeOne Pages 导入该 GitHub 仓库，选择实际推送的分支。框架选无框架，根目录和输出目录均为 `./`，安装命令和构建命令留空。部署后打开生成的 Pages 地址。若两个项目放在同一仓库，请各建一个 Pages 项目，各自使用对应的项目子目录作为根目录。

本项目的操作在浏览器中完成。公开部署前，请由项目维护者确认自有代码和素材的授权范围，再添加相应的开源许可证。第三方素材沿用各自的许可。

这是自由名片编辑器的独立版本。选图、排版和 PNG 导出在浏览器内完成。公开版可直接打开，原主站反馈和登录功能由主站版本提供。fonts 目录保留 11 套字体各自的许可证，只有选用内置字体时才会下载对应文件。部署须完整上传 fonts 目录。
